# Figures

Publication figures generated from the numerical results.

## `draft_<dataset_commit>/`

Automatically generated working figures associated with a specific
numerical dataset / Git commit.

These directories are ignored by Git because they can be reproduced
from the plotting scripts and the corresponding numerical results.

## `release/`

Optional location for selected final figures used in a manuscript,
submission, or collaborator release.

Only figures intentionally selected for a release should be stored here.
